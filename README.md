# KING EVOLUTION Launcher

El launcher se publica como `KING EVOLUTION.exe`. En Linux se puede intentar ejecutar con Wine usando `wine "KING EVOLUTION.exe"`; la compatibilidad depende de la configuración de Wine.

El paquete `KING LOADER vX.Y.Z.rar` se descomprime en una carpeta `KING LOADER` que contiene `KING EVOLUTION.exe` y `Tutorial_Launcher.txt`.

En Windows, el launcher instala automáticamente las nuevas versiones. Si ejecutas el `.exe` en Linux mediante Wine, avisa cuando hay un release nuevo y abre GitHub para descargar el nuevo `KING EVOLUTION.exe`; cierra el launcher y reemplaza el archivo manualmente. Un launcher Linux nativo requiere un asset Linux correspondiente en el release.
