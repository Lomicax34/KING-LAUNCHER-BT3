# KING EVOLUTION Launcher

El launcher se publica como `KING EVOLUTION.exe` para Windows. En Linux, si se ejecuta mediante una capa de compatibilidad, las actualizaciones abren el release de GitHub para descargar y reemplazar manualmente el ejecutable. Para una ejecución Linux nativa debe publicarse un ejecutable Linux en el release.

El paquete `KING LOADER vX.Y.Z.rar` se descomprime en una carpeta `KING LOADER` que contiene `KING EVOLUTION.exe` y `Tutorial_Launcher.txt`.

El launcher no descarga ni distribuye archivos ISO. El usuario debe proporcionar su propio archivo `.iso`; el botón **OBTENER ISO** muestra un aviso y permite abrir el [Discord oficial de KING LOADER](https://discord.gg/weVnQaRMcP). En Windows, el launcher descarga la actualización mientras permanece abierto y muestra el porcentaje en la barra y el registro. Cuando termina, **CERRAR Y ACTUALIZAR** cierra la versión actual, sustituye el ejecutable y abre la versión nueva. En Linux, avisa cuando hay un release nuevo y abre GitHub para descargar el ejecutable adecuado y reemplazarlo manualmente. El publicador actualiza también este README en el repositorio.
