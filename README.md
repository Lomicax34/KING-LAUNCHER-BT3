# KING EVOLUTION Launcher

El launcher se publica como `KING EVOLUTION.exe` para Windows. En Linux, si ejecutas el launcher mediante una capa de compatibilidad, la comprobación de actualizaciones abre el release de GitHub para que descargues y reemplaces manualmente el ejecutable. Para una ejecución Linux nativa debe publicarse un ejecutable Linux en el release.

El paquete `KING LOADER vX.Y.Z.rar` se descomprime en una carpeta `KING LOADER` que contiene `KING EVOLUTION.exe` y `Tutorial_Launcher.txt`.

El launcher no descarga ni distribuye archivos ISO. El usuario debe proporcionar su propio archivo `.iso`; el botón **OBTENER ISO** muestra este aviso y permite abrir el [Discord oficial de KING LOADER](https://discord.gg/weVnQaRMcP). En Windows, el launcher instala automáticamente las nuevas versiones. En Linux, avisa cuando hay un release nuevo y abre GitHub para que descargues el ejecutable adecuado y lo reemplaces manualmente. El publicador actualiza también este README en el repositorio.
